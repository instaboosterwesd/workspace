# Exact Touch-Point Specification — 1.70x and 2.00x

## Coordinate convention

Original reference frame:
**1394 × 644 px**

Origin:
**(0,0) = top-left**

Graph baseline:
**Y ≈ 574**

Graph start:
**X ≈ 42, Y ≈ 574**

---

## TARGET A — 1.70x

### Target coordinate
Use the curve/fill meeting point:

**X ≈ 1074 px**  
**Y ≈ 110 px**

Target:
`(1074, 110)`

### Relative to graph start

`dx = 1074 - 42 = 1032 px`

`dy = 110 - 574 = -464 px`

So the graph travels approximately:
- **1032 px horizontally**
- **464 px upward**

### Local tangent

Approximate tangent:
**39.5° upward from horizontal**

Screen-space slope:
**dy/dx ≈ -0.82**

### Important

Do not force the whole graph into a straight line between `(42,574)` and `(1074,110)`.

These coordinates define the endpoint only.

The path between them must be a smooth accelerating curve matching the reference.

---

## TARGET B — 2.00x

### Target coordinate

Use the curve/fill meeting point:

**X ≈ 1222 px**  
**Y ≈ 184 px**

Target:
`(1222, 184)`

### Relative to graph start

`dx = 1222 - 42 = 1180 px`

`dy = 184 - 574 = -390 px`

So the graph travels approximately:
- **1180 px horizontally**
- **390 px upward**

### Local tangent

Approximate tangent:
**31.3° upward from horizontal**

Screen-space slope:
**dy/dx ≈ -0.61**

---

## Comparison

| State | Multiplier | X | Y | Width from start | Height above baseline | Tangent |
|---|---:|---:|---:|---:|---:|---:|
| Upper target | ~1.70x | ~1074 | ~110 | ~1032 px | ~464 px | ~39.5° |
| Lower target | 2.00x | ~1222 | ~184 | ~1180 px | ~390 px | ~31.3° |

The **1.70x state is visually higher** than the 2.00x state.

That is the key behavior to preserve if the animation is being modified to alternate between these two target positions.

---

## Implementation coordinates

Recommended logical constants:

```text
GRAPH_START = (42, 574)

TARGET_1_70 = (1074, 110)
TARGET_2_00 = (1222, 184)

ANGLE_1_70 ≈ 39.5°
ANGLE_2_00 ≈ 31.3°
```

Treat these as reference measurements, not arbitrary design values.

For responsive implementations, convert them to normalized coordinates before scaling:

```text
TARGET_1_70:
x = 0.770
y = 0.171

TARGET_2_00:
x = 0.877
y = 0.286
```

The normalized values are based on the full 1394×644 source frame.
